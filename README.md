# 🌱 ONG Anjos do Poço

Site institucional desenvolvido para a **ONG Anjos do Poço**, com o objetivo de apresentar a organização, seus projetos, ações e informações de contato de forma clara, acessível e responsiva.

🔗 **[Acessar o site](https://viniziano.github.io/Ong-Anjos-Do-Poco/)**

---

## 📌 Sobre o projeto

O projeto consiste no desenvolvimento de uma plataforma web para a **ONG Anjos do Poço**, reunindo informações sobre a organização, seus trabalhos e formas de contato em um único ambiente.

A aplicação foi desenvolvida com foco em organização, responsividade e facilidade de navegação, proporcionando uma experiência adequada em diferentes dispositivos.

## 🎨 Organização dos estilos

Os arquivos CSS foram organizados em diferentes diretórios para facilitar a manutenção e separação das responsabilidades.

    css/
    ├── base/
    ├── components/
    ├── fixes/
    └── pages/

### Base

Contém estilos gerais utilizados como base para a interface.

### Components

Reúne estilos relacionados a componentes reutilizáveis da interface.

### Fixes

Contém ajustes e correções específicas de determinados elementos ou comportamentos visuais.

### Pages

Organiza estilos específicos de cada página da aplicação.

## 💻 Como executar localmente

### 1. Clone o repositório

    git clone https://github.com/ViniZiano/Ong-Anjos-Do-Poco.git

### 2. Acesse a pasta do projeto

    cd Ong-Anjos-Do-Poco

### 3. Execute o projeto

Abra o arquivo `index.html` diretamente no navegador ou utilize uma extensão como **Live Server** no VS Code.

Não é necessário instalar dependências para executar a interface principal do projeto.
